# WA-GAPS-01: textMatch + retry de arranque en frío — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Filtro por contenido en triggers de WhatsApp (textMatch) + retry único honesto para arranque en frío del motor local en los dos draft writers.

**Architecture:** textMatch vive en el modelo de triggers (`trigger.dart`): el evento de notificación transporta el texto del mensaje (`interpretableText`), `evaluateTrigger` lo matchea por substring case-insensitive, el parser extrae el filtro de lenguaje natural (comillas o resto) y la UI lo muestra. El retry frío es un helper compartido (`cold_start_retry.dart`) consumido por ambos draft writers; un reintento solo si la salida es vacía y rápida (<3s).

**Tech Stack:** Dart 3 (records, switch expressions), Flutter, LLMEngineClient (`Future<LLMResult> generate({required String prompt, double temperature = 0.7, int maxTokens = 256})`), sin cambios Kotlin.

**Spec:** `docs/superpowers/specs/2026-09-04-wa-gaps-design.md`

- [ ] **Step 2: Helper de extracción texto+goal**

Añadir método a `TriggerParser` (tras `_goalAfterClause`):

```dart
  /// Del resto tras el verbo extrae (textMatch, goal): el texto antes de la
  /// coma (sin coma → todo) y el goal tras la coma. Comillas → contenido
  /// entre comillas. Vacío → textMatch null (no se inventa un filtro).
  (String?, String) _textAndGoal(String rest) {
    final r = rest.trim();
    final comma = r.indexOf(',');
    final textPart = (comma >= 0 ? r.substring(0, comma) : r).trim();
    final goalRest = comma >= 0 ? r.substring(comma + 1).trim() : '';
    if (textPart.isEmpty) return (null, goalRest);
    final quoted = RegExp(r'''['"](.+?)['"]''').firstMatch(textPart);
    if (quoted != null) {
      final inner = quoted.group(1)!.trim();
      return (inner.isEmpty ? null : inner, goalRest);
    }
    return (textPart, goalRest);
  }
```

### Task 4: Helper de retry por arranque en frío

**Files:**
- Create: `nanoMOBILE/flutter_app/lib/features/automation/engine/model/cold_start_retry.dart`

**Interfaces:**
- Consumes: `LLMEngineClient.generate` (`core/services/llm_engine_client.dart:143`).
- Produces: `generateWithColdRetry(LLMEngineClient client, {required String prompt, required double temperature, required int maxTokens, Duration threshold = const Duration(seconds: 3)}) → Future<String>`. Tasks 5 y 6 dependen.

- [ ] **Step 1: Crear el helper**

```dart
/// Retry único honesto para arranque en frío del motor local.
///
/// La primera llamada tras arrancar el motor devuelve a veces texto vacío en
/// ~45ms (warm-up, evidencia WA-PHYS-EMM): un reintento convierte ese fallo
/// en respuesta real. Solo se reintenta si la salida fue vacía Y rápida
/// (< [threshold]): vacío tras generación larga = fallo honesto, no frío.
/// Las excepciones NO se reintentan aquí — las maneja cada consumidor.
library;

import 'package:flutter/foundation.dart';

import '../../../../core/services/llm_engine_client.dart'
    show LLMEngineClient;

Future<String> generateWithColdRetry(
  LLMEngineClient client, {
  required String prompt,
  required double temperature,
  required int maxTokens,
  Duration threshold = const Duration(seconds: 3),
}) async {
  final stopwatch = Stopwatch()..start();
  final first = await client.generate(
    prompt: prompt,
    temperature: temperature,
    maxTokens: maxTokens,
  );
  final firstText = first.text.trim();
  if (firstText.isNotEmpty || stopwatch.elapsed >= threshold) {
    return firstText;
  }
  debugPrint('[draft] reintento por arranque en frío');
  final second = await client.generate(
    prompt: prompt,
    temperature: temperature,
    maxTokens: maxTokens,
  );
  return second.text.trim();
}
```
